# AureonX

Simulated multi-asset trading platform (demo funds only). Next.js 16 on Cloudflare Workers via OpenNext, with Supabase.

Start with `CLAUDE.md` (what has shipped and the rules), then `docs/decisions.md` and `docs/build-order.md`.

```sh
pnpm install
cp .env.example .env.local   # fill in Supabase values
pnpm dev
```
